Análises de mineração de dados para apoio à decisão

Site estático com três estudos de caso em datasets do Kaggle, cada um com EDA, mineração (clusterização, classificação, associação/limiar) e recomendações no formato decisão. Dois estudos usam dados sintéticos ilustrativos (avisado em cada página); o de fraude usa os dados reais. A síntese comparativa está em Relatório.

Os três casos

E-commerce brasileiro (Olist) — ver análise

Dados sintéticos ilustrativos (seed 42, esquema da coleção Olist).

  • Volume: 6000 pedidos, 7337 itens (join orders + order_items + customers).
  • Técnicas: KMeans k=4 sobre RFM, árvore de decisão (acurácia 0,80), co-ocorrência de categorias.
  • Holofote: o atraso médio cresce nas notas baixas — atraso > 7 dias derruba o review; priorizar estoque regional protege a satisfação.

Saúde (Diabetes) — ver análise

Dados sintéticos ilustrativos (fallback seed 42, n=5000, prevalência 0,21; fonte real: BRFSS 2015).

  • Volume: 5000 indivíduos, 20 colunas de indicadores de saúde.
  • Técnicas: KMeans k=3 (perfis de risco), árvore de decisão (acurácia 0,559), Apriori (19 itemsets, 6 regras).
  • Holofote: regra de triagem — pressão alta + colesterol alto + idade avançada, ou IMC ≥ 30 + sedentarismo, identifica quem encaminhar ao rastreio prioritário.

Fraude em cartão de crédito — ver análise

Dados reais do Kaggle (mlg-ulb/creditcardfraud).

  • Volume: 284.807 transações europeias, 492 fraudes (0,17%).
  • Técnicas: KMeans, árvore vs. regressão logística, análise de limiar por custo esperado.
  • Holofote: perder uma fraude custa 50× uma revisão manual (FN=500 vs FP=10) — o limiar de custo mínimo (0,98; precision 0,562, recall 0,831) privilegia recall.
